# 🥐 Tulpar Fırın & Pastane - Frontend Projesi

Bu proje, bir yerel işletme (fırın/pastane) için tasarlanmış, kullanıcı dostu ve modern bir web arayüzü çalışmasıdır. Temel web teknolojileri kullanılarak, temiz kod prensiplerine uygun bir klasör yapısıyla geliştirilmiştir.

## ✨ Özellikler
- **Responsive Tasarım:** Tüm ekran boyutlarında (mobil, tablet, masaüstü) sorunsuz görüntüleme.
- **Modern Klasör Yapısı:** Varlıkların (assets), stillerin (css) ve betiklerin (js) düzenli organizasyonu.
- **Görsel Odaklı Arayüz:** Ürünlerin öne çıkarıldığı estetik tasarım.

## 🛠 Kullanılan Teknolojiler
- **HTML5:** Semantik ve erişilebilir yapı.
- **CSS3:** Özel stil tanımlamaları ve layout yönetimi.
- **JavaScript:** Etkileşimli öğeler.

## 📁 Proje Yapısı
Proje, yönetilebilirliği artırmak için şu şekilde organize edilmiştir:
- `/assets`: Resimler, logolar ve ikonlar.
- `/css`: Tasarımı belirleyen stil dosyaları.
- `/js`: Dinamik özellikleri yöneten scriptler.
- `/html`: Yan sayfalar (hakkımızda, ürünler vb.).
- `index.html`: Web sitesinin ana giriş noktası.

## 🚀 Kurulum
Projeyi yerel bilgisayarınızda görüntülemek için:
1. Depoyu indirin veya klonlayın.
2. `index.html` dosyasını tarayıcınızda açın.
